# Проза жизни — сайт театра импровизации

Статический одностраничный сайт: HTML + CSS + ванильный JavaScript. Сборка не нужна.

## Запуск

Откройте `index.html` в браузере — всё работает и без сервера. Для локального сервера:

```bash
npx serve .
```

## Что где лежит

- `index.html` — структура страницы
- `styles.css` — стили, адаптив, анимации
- `script.js` — вкладки форматов, отзывы, FAQ, меню, валидация формы
- `config.js` — **все тексты и данные**, которые нужно заменить

## Замена данных

Откройте `config.js` и заполнитеблоки:

- `brand` — название труппы, город, цифры в первом экране;
- `contacts` — почта, телефон, телеграм, площадка; ссылки в контактах обновятся автоматически;
- `formats` — 4 формата: название, описание, длительность, состав, этапы;
- `team` — участники (инициалы, имя, роль, год, фото);

## Фото участников

1. Положите изображения в папку `photos` рядом с `index.html` (например, `photos/anna.jpg`).
2. В `config.js` у нужного участника заполните поле `photo`:

```js
{ name: 'Анна', role: 'Импровизатор', initials: 'А', since: 'в труппе с 2021', photo: 'photos/anna.jpg' }
```

Пустое поле `photo: ''` означает, что вместо фото покажется инициал. Изображение автоматически обрезается по формату карточки; лучше всего подходят квадратные или вертикальные снимки от 600 px. Если файл не найдён, карточка откатится на инициал.
- `events` — афиша: число, месяц, день недели, название, время, площадка, цена, статус;
- `reviews` — отзывы зрителей;
- `faq` — вопросы и ответы;
- `school` — параметры курса.

Количество участников, событий, отзывов и вопросов может быть любым — блоки строятся автоматически.

## Важно

Форма обратной связи сейчас только клиентская: она проверяет поля и показывает сообщение об успехе, но **не отправляет данные**. Чтобы принимать заявки, подключите backend, Formspree/Telegram-бот или замените обработчик в `script.js`.

Шрифты подключены с Google Fonts; при отсутствии сети используется системный запасной шрифт.
